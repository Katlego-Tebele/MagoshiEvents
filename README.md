## 🔧 Customization Guide

### Changing Colors
Edit the CSS variables in `css/style.css`:

```css
:root {
    --blush-pink: #F7DCE5;
    --champagne-gold: #C9A45C;
    --deep-burgundy: #722F47;
    --ivory-white: #FFF9F4;
    --elegant-charcoal: #252525;
    --soft-lavender: #EAE0F5;
}
```

### Changing Contact Information
Edit in `index.html`:
- Line 8: Meta description
- Line 36-48: Structured data
- All WhatsApp links: Search for `27829466671` and replace
- Footer contact details
- Contact section

### Adding More Gallery Images
1. Add images to `assets/images/gallery/` with sequential naming
2. Copy a gallery item `<div>` in `index.html` and update the image source and caption
3. CSS will automatically adjust the grid layout

### Changing Fonts
Replace Google Fonts links in `<head>` of `index.html` and update CSS variables:

```css
--font-heading: 'Your Heading Font', serif;
--font-body: 'Your Body Font', sans-serif;
```
